# الحسام للتسوق المنزلي

نسخة أولية تعمل على Next.js وتدعم العربية وRTL.

## النشر على Vercel
- Framework: Next.js
- Build command: `npm run build`
- لا توجد متغيرات بيئية مطلوبة لهذه النسخة الأولية.

الخطوة التالية بعد نجاح النشر: ربط Supabase لإدارة المنتجات والطلبات وحساب الإدارة ورفع إيصالات التحويل.
